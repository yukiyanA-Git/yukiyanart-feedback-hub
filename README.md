# 統合要望受付窓口 & 公式お知らせアプリ (Feedback & Release Hub)

自社で展開する複数アプリの要望・不具合報告受付、公式アップデート情報発信、および自社アプリのクロスプロモーション（広告面）を兼ねた統合窓口プロジェクトです。

---

## 🌟 主な機能・特徴

1. **自社アプリ一覧（自社広告 兼 入口）**
   - 洗練されたアイコン配置で、自社他アプリへの興味・回遊を促進。
   - 各アプリの設定画面から飛んできた際、Deep Link（URLスキーム）経由で該当アプリを**赤枠＋目立つエフェクトで強調表示**。

2. **手動タップで投稿ポップアップ起動 (パターンB)**
   - 赤枠強調されたアプリ（または他のアプリ）をタップすると、投稿ポップアップ（モーダル）が開きます。
   - 完全匿名で修正要望・内容要望をすばやく送信可能。

3. **送信後の掲示板着地 & 権限制御**
   - 送信後はそのまま選択アプリの掲示板に着地。みんなの要望や開発者の返信を閲覧可能。
   - **一般ユーザー権限**: 閲覧と自身の投稿のみ可能（他人の投稿への返信は不可）。
   - **管理者権限**: チャット形式で各要望に返信可能。

4. **公式アップデート・お知らせタブ**
   - 管理者専用発信エリア。アプリごとの修正完了報告や、新バージョンリリース情報を一括発信。
   - 今後アプリが増えても柔軟に拡張可能。

### 🧪 プロトタイプで体験できる機能
1. **模擬起動リンクボタン**（画面上部）:
   - 「アプリAから起動」「アプリBから起動」をクリックすると、実際のDeep Link経由でアプリが起動した際の「赤枠ハイライト」動作をテストできます。
2. **投稿モーダル**:
   - 赤枠（または各アプリカード）をタップすると、記入画面が開きます。送信すると掲示板に着地します。

   - 「一般ユーザーモード」と「管理者モード」をトグルで切り替え可能です。管理者モードにすると、各要望への返信フォームや、お知らせ投稿ボタンが現れます。

## 🔗 各アプリへのディープリンク組み込み方法 (実装ガイド)

今後開発する各アプリ（アプリA, アプリB...）の設定画面ボタンには、以下のようなURLスキーム/Universal Linksをセットします。

```dart
// Flutterの場合の呼び出し例 (url_launcherパッケージ)
final Uri url = Uri.parse('feedbackhub://open?app_id=app_a');
if (await canLaunchUrl(url)) {
  await launchUrl(url);
}
```
